# 대화형 랜딩 페이지

몇 번의 클릭만으로 모든 랜딩 페이지(Marketo 랜딩 페이지 또는 사용자 지정)에 Dynamic Chat 대화형 흐름을 설치하고 링크 또는 버튼을 변환하여 대화형 참여를 트리거할 수 있습니다.

잠금을 해제할 수 있는 사용 사례 -

- 방문자가 모임을 예약할 수 있도록 합니다.
- 검증 질문
- 방문자 선택/관심사에 따른 권장 콘텐츠
- 문서 공유 및 참여 추적
